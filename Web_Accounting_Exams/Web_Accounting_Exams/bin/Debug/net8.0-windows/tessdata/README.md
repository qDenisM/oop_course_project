# Система электронного учета экзаменов (Web Accounting Exams)

Настольное приложение для учета экзаменов, разработанное на C# с использованием WPF и паттерна MVVM.

## Описание

Система предназначена для управления процессом подачи заявок на экзамены, отслеживания результатов и управления данными абитуриентов и университетов.

## Функциональность

### Функции администратора:
- Подтверждение участия в экзамене
- Оповещение клиентов о результатах сдачи (почта)
- Добавление, удаление, редактирование экзаменов
- Добавление, удаление, редактирование расписания экзаменов
- Добавление, удаление, редактирование вузов

### Функции клиента (абитуриента):
- Регистрация и авторизация
- Подача заявки на экзамен
- Загрузка сертификатов ЦТ, аттестата
- Просмотр информации о своих результатах
- Просмотр информации о расписании экзаменов
- Редактирование персональных данных
- Просмотр информации о учебных заведениях

## Технологии

- **.NET 8.0** - платформа разработки
- **WPF** - пользовательский интерфейс
- **Entity Framework Core** - ORM для работы с базой данных
- **SQL Server / LocalDB** - база данных
- **Material Design** - дизайн интерфейса
- **MVVM Pattern** - архитектурный паттерн
- **CommunityToolkit.Mvvm** - библиотека для MVVM

## Требования

- Windows 10/11
- .NET 8.0 SDK
- SQL Server LocalDB (входит в состав Visual Studio) или SQL Server Express
- Visual Studio 2022 или выше (рекомендуется)

## Установка и настройка

1. Клонируйте репозиторий или скачайте проект
2. Откройте решение `Web_Accounting_Exams.sln` в Visual Studio
3. Восстановите NuGet пакеты:
   ```
   dotnet restore
   ```
4. Убедитесь, что SQL Server LocalDB установлен и запущен
5. Строка подключения к базе данных находится в `ApplicationDbContext.cs`:
   ```csharp
   "Server=(localdb)\\mssqllocaldb;Database=WebAccountingExams;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True"
   ```
6. При первом запуске база данных будет создана автоматически с тестовыми данными

## Запуск приложения

1. Запустите проект из Visual Studio (F5)
2. При первом запуске будет создана база данных с тестовыми данными:
   - **Администратор**: `admin@test.com` / `admin`
   - **Абитуриент**: `student@test.com` / `student123`

## База данных

База данных создается автоматически при первом запуске приложения через Entity Framework Core Code First подход.

### Основные таблицы:
- **Users** - пользователи системы
- **Exams** - экзамены
- **ExamSchedules** - расписание экзаменов
- **Universities** - университеты
- **Specialities** - специальности
- **SpecialitySubjects** - предметы для специальностей
- **ExamApplications** - заявки на экзамены
- **ExamResults** - результаты экзаменов
- **UniversityApplications** - заявки в университеты
- **Certificates** - сертификаты

## Настройка email уведомлений

Для работы отправки email уведомлений необходимо настроить параметры в `EmailService.cs`:
- SMTP сервер
- Порт
- Учетные данные (логин и пароль)

По умолчанию используется Gmail SMTP, но можно настроить любой другой SMTP сервер.

## Разработка

### Добавление новой функциональности

1. Создайте модель в папке `Models/`
2. Добавьте модель в `ApplicationDbContext`
3. Создайте ViewModel в папке `ViewModels/`
4. Создайте View (XAML) в папке `Views/`
5. Свяжите View с ViewModel через DataContext

### Создание миграций

```bash
dotnet ef migrations add MigrationName
dotnet ef database update
```
